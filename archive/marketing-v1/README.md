# Marketing site v1 (Loomover, GSAP story page)

Kept as a reference copy when the marketing site was replaced by the newer Claude Design handoff.
Live from September 2026 until the replacement; also in git history at commit 34bcdbd.

- `page.tsx` — the page itself (hero + phone sign-up, ticker, listings preview, how it works,
  categories, workshop, FAQ, banner, footer).
- `MarketingMotion.tsx` — all GSAP scroll/intro animation for it.
- `StickyHeader.tsx` — header that hides on scroll-down and returns on scroll-up.
- `PhoneSignupForm.tsx` — the inline phone sign-up used in the hero and closing banner (still in
  use elsewhere at the time of archiving).
- `assets/` — copies of the images it used from public/marketing.

Nothing here is imported by the app; it is a snapshot for reference only.
